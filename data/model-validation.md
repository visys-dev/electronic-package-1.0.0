# Перевірка моделі ERD-01

25.10.2026. Три подання створено Drawio MCP у форматі XML; основні результати збережено в data/erd.drawio та в загальному комплекті. Експорт не виконувався за рішенням користувача.

Перевірено: XML читається; ID унікальні в кожному аркуші; всі кінці зв’язків існують; Times New Roman 14 для всіх написів; 16 сутностей представлені хоча б в одному поданні. Повторювані сутності на різних аркушах означають ті самі таблиці. Самопосилання tickets.previous_ticket_id показано через повторний блок тієї самої таблиці; tickets.queue_id має графічний зв’язок із queues. Всі FK представлені на відповідних аркушах. Повні атрибути наведено у словнику.

- erd-access: 45 елементів; 6 зв’язків.
- erd-tickets: 82 елементів; 16 зв’язків.
- erd-events: 51 елементів; 7 зв’язків.

Структурна перевірка не доводить читабельність після експорту/масштабування або виконання обмежень у конкретній СКБД. Фізичний DDL та міграції не створено; сховище не розгорнуто. TEST-01–TEST-39 не виконувалися.
