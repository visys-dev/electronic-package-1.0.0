# Макети та суттєві стани

Редакція: 05.11.2026. Низькодеталізовані проєктні макети; дані синтетичні. Позначення обсягу означають план реалізації.

| ID / файл у `ux/mockups/` | Призначення | Потік / API | Обсяг |
|---|---|---|---|
| UI-01 / `ui-01.drawio` | Вхід і узагальнена відмова | Усі; API-LOGIN | Прототип |
| UI-02 / `ui-02.drawio` | Створення: тема, опис, категорія | FLOW-01; API-14/01 | Прототип |
| UI-03 / `ui-03.drawio` | Помилка поля зі збереженням решти введення | FLOW-01; API-01 | Прототип |
| UI-04 / `ui-04.drawio` | Надсилання, повторна кнопка недоступна | FLOW-01; API-01 | Прототип |
| UI-05 / `ui-05.drawio` | Підтверджене створення й публічна картка | FLOW-01; API-03/07/08/09 | Прототип |
| UI-06 / `ui-06.drawio` | Порожній дозволений список | FLOW-01; API-02 | Прототип |
| UI-07 / `ui-07.drawio` | Перше призначення координатором | FLOW-02; API-15/04 | Прототип |
| UI-08 / `ui-08.drawio` | Початок роботи, відповідь і публічне рішення | FLOW-02; API-06/07 | Прототип |
| UI-09 / `ui-09.drawio` | Підтвердження або повернення рішення | FLOW-03; API-06 | Частково в прототипі |
| UI-10 / `ui-10.drawio` | Конфлікт версії / рішення, чернетка збережена | FLOW-02/03; API-04/06/07 | Прототип |
| UI-11 / `ui-11.drawio` | Закрита заявка, лише читання | FLOW-03; API-03/08/09 | Прототип |
| UI-12 / `ui-12.drawio` | Відсутня або недоступна заявка | Усі; API-03 | Прототип |

UI-08 показує стан «У роботі». Дія «Почати роботу» відображається лише в попередньому стані «Призначена»; рішення — лише в «У роботі». Це умови відображення, сервер повторює перевірку незалежно від кнопок. Дії повернення на UI-09 належать повному проєкту. Макети не обіцяють адміністративних екранів, внутрішніх сповіщень чи повного розрахунку строків у прототипі.

Службовий пояснювальний рядок макета не є полем API. Номер і стан беруться з відповіді; «Ви» визначається порівнянням ID з API-ME. Імена допустимих виконавців доступні координатору через API-15. API повертає authorId історії/повідомлень, тому інтерфейс не повинен вигадувати імена авторів або використовувати адміністративний список користувачів для їх отримання: для інших авторів можливий короткий ідентифікатор.

Створено через Drawio MCP, Times New Roman 14; копії в загальному комплекті. Інтерактивність, адаптивність і читабельність після експорту ще не перевірені; експортує користувач.
