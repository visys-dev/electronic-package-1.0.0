# План перевірки доступності

Редакція: 05.11.2026. Основа: NFR-05/06 та WCAG 2.2, редакція 12.12.2024 [19]. Макети не є інтерактивною реалізацією: Tab-порядок, screen reader та фактичний контраст браузера не перевірено. TEST-25/26 не виконано.

| Об’єкт | Проєктна поведінка | Спосіб майбутньої перевірки |
|---|---|---|
| FLOW-01, UI-01–06 | Порядок: заголовок/навігація → логін/пароль → форма тема/опис/категорія → основна дія → результат | Увесь шлях Tab/Shift+Tab, Enter; вибір категорії клавіатурою; відсутність пастки; WCAG 2.1.1/2.1.2 |
| FLOW-02, UI-07/08/10 | Список → картка → виконавець → призначення; після входу спеціаліста — початок → рішення → результат | Видимий фокус у кожній дії, відсутність фокусу на недоступних контролах; 2.4.7 |
| FLOW-03, UI-09/11 | Рішення перед кнопками; підтвердження має однозначну назву; повернення — пояснення перед надсиланням | Клавіатурний шлях для реалізованих гілок; після закриття немає полів зміни |
| UI-03, 422 | Постійний label, aria-describedby для помилки, aria-invalid=true; підсумок містить посилання на поля | Порожні/надмірні значення та неактивна категорія; текст помилки визначає поле; 3.3.1 |
| UI-04/05 | Текстовий статус, aria-busy під час запиту, оголошення результату через status; фокус не зникає при блокуванні кнопки | Клавіатура й допоміжні технології після реалізації; відсутність подвійного надсилання |
| UI-10 | Фокус на повідомлення конфлікту; чернетка не втрачається; «Оновити картку» не надсилає зміну | Два клієнти, застаріла version; TEST-26/35 |
| Усі стани | Помилка/стан позначені словами, не лише кольором; звичайний текст #111111 на #FFFFFF, focus #000000 | Майбутнє вимірювання фактичних стилів і станів; для звичайного тексту проєктний орієнтир контрасту 4,5:1 за 1.4.3 |

Вихідне оформлення схем Times New Roman 14 не визначає кінцевий CSS інтерфейсу. Для обраного інтерфейсу на Jinja2, HTML/CSS і JavaScript типографіку, адаптивне компонування та поведінку компонентів належить визначити й перевірити під час реалізації; оцінка 12 статичних макетів не підтверджує повної відповідності WCAG A/AA. Перевірка контрасту додаткова до чотирьох уже визначених критеріїв; NFR-05/06 не розширюються до повної сертифікації.

## Часткова перевірка прототипу — 06.11.2026

Через Chromium пройдено FLOW-01–FLOW-03 мишею; для помилкової порожньої теми перевірено aria-invalid, aria-describedby, переведення фокусу й збереження опису. Доказ — tests/evidence/2026-11-06/ui-smoke.json. Це не повний TEST-25/26 і не підтвердження всіх критеріїв WCAG.
