# Користувацькі потоки

Моделі — проєктні. Базові гілки FLOW-01–FLOW-03 перевірено в прототипі 06.11.2026; повні клавіатурні потоки й усі винятки не перевірені. Основа: BR-01–BR-10, AC-01–AC-31, API-01–API-15.

| ID | Джерело | Учасники та основний шлях | Винятки / перевірки |
|---|---|---|---|
| FLOW-01 | `ux/flows/create-ticket.drawio` | Заявник: вхід → форма → надсилання → номер → картка; API-LOGIN/14/01/03 | 422 зі збереженням полів; невідомий результат — той самий ключ і вміст; TEST-01/02/03/34 |
| FLOW-02 | `ux/flows/process-ticket.drawio` | Координатор: список → нова заявка → призначення; призначений спеціаліст: початок → публічне рішення; API-02/03/15/04/06 | Некоректний виконавець, 409, недозволений перехід; TEST-05/06/29/32/35 |
| FLOW-03 | `ux/flows/confirm-solution.drawio` | Власник: картка → чинне рішення → підтвердження → закрита заявка; API-03/08/06 | Змінене рішення — перечитування; повернення з поясненням — Проєктування; TEST-07/08/30/31/35 |

Спільні гілки: 401 — очистити захищене представлення та перейти до входу; 403 — пояснити недозволену дію; 404 — UI-12 без чужих даних; 503/timeout — не показувати успіх без підтвердження. Для зміни стану після втрати відповіді спочатку перечитати картку й історію: довільні команди не повторюються автоматично.

В одному обліковому записі можуть поєднуватися учасники FLOW-02 та FLOW-03. Власність не скасовує чинних дозволів підтримки; публічна проєкція власної заявки зберігається. Правила — `security/access-matrix.md`.
