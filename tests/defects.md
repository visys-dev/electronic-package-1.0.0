# Виявлені невідповідності та обмеження

Дата: 06.11.2026.

| ID | Спостереження | Стан / перевірка |
| --- | --- | --- |
| DEF-01 | OpenAPI вказував Path=/api/v1, пізніша політика сеансів — Path=/ | Виправлено опис контракту; реалізація використовує /. Повна валідація — contract.json; cookie перевірено через HTTP |
| DEF-02 | У ранньому UI показувалися технічні коди/JSON історії | Замінено українськими описами; актуальний ui-closed.png |
| DEF-03 | Помилка поля показувалася лише загальним повідомленням | Додано fieldErrors, aria-invalid/aria-describedby й фокус на поле. Для порожньої теми перевірено збереження опису; повний TEST-26 ще відкритий |
| DEF-04 | Клієнтське maxlength не відповідало способу підрахунку пароля в проєкті | Прибрано HTML maxlength; сервер зберігає межу 64 кодових точок. Введення 64 emoji перевірено через браузер, межі 64/65 — локальними тестами; повний TEST-21 не завершено |


Відсутні функції повного проєкту перелічено в docs/prototype-scope.md; це межі реалізації, а не успішно пройдені перевірки. Зокрема, не реалізовано семиденне очищення діагностики, повний контроль строків, internal, сповіщення, звіти й адміністративні API. Повний аудит безпеки, навантаження та доступність залишаються відкритими.

Сценарії, очікування й межі підтвердження цих чотирьох виправлень також наведено в Д.7 додатка Д. Це систематизація наявних спостережень, не нові дефекти чи новий прогін тестів.
