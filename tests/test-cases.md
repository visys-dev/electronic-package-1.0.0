# План перевірок

Актуалізація: 06.11.2026. 39 випадків; завершено й пройдено 11, решта 28 не завершені в повному обсязі. Це специфікація ручних/майбутніх автоматизованих перевірок, а не програмний тестовий набір. Для випадків з кількома варіантами кожний варіант виконується й фіксується окремо; часткове виконання не дає статусу «пройдено» всьому випадку. Складені випадки не означають повного покриття всіх комбінацій. Перевірка нереалізованої гілки позначається «не виконано», не «пройдено».
