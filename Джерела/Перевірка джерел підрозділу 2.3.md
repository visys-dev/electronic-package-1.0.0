# Перевірка джерел підрозділу 2.3

Дата фактичного відкриття: 05.11.2026. Використано офіційні сторінки OWASP та фіксовану рекомендацію W3C. Дати публікації динамічних сторінок OWASP не встановлено. Наведені нотатки не є архівними копіями сторінок або результатами тестування програми.

Нові ID SRC-033–SRC-035 відповідають першій появі [31]–[33] у тексті 2.3. Інші джерела повторно використані без нової бібліографічної нумерації. Строки TTL, retention, ліміти спроб, набір ролей та правила власної заявки не подаються як встановлені цими джерелами.

Статичні макети не підтверджують keyboard navigation, фактичний контраст CSS або повну відповідність WCAG. Наявність захисного рішення не підтверджує його ефективності. Параметри бібліотеки, performance, серверні відмови та журнали потребують перевірки після реалізації. Правових норм оброблення PII цими джерелами не встановлено.

Уточнення 05.11.2026 після перевірки межі пароля: SRC-034 / [32], Password Strength Controls, рекомендує максимальну дозволену довжину щонайменше 64 символи та заборону непомітного обрізання. За прямою вказівкою користувача проєкт приймає максимум 64, нові паролі — 15–64. Конкретна верхня межа є рішенням проєкту; твердження, що довші паролі ніде не приймаються, не використовується.
