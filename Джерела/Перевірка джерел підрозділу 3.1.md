# Перевірка джерел підрозділу 3.1

Дата: 06.11.2026. Перевірено офіційні сторінки, додано SRC-036–SRC-039 за порядком появи [34]–[37].

- SRC-036: https://fastapi.tiangolo.com/advanced/templates/ — Jinja2Templates та віддавання шаблонів FastAPI. Це механізм, не порівняльне дослідження фреймворків.
- SRC-037: https://docs.sqlalchemy.org/en/20/dialects/postgresql.html#module-sqlalchemy.dialects.postgresql.psycopg — psycopg 3 і вибір синхронного/асинхронного рушія. Використано документацію гілки 2.0, яка відповідає встановленій 2.0.57; новішу гілку не представляти встановленою.
- SRC-038: https://alembic.sqlalchemy.org/en/latest/tutorial.html — міграційне середовище й версії. Конкретний незмінний знімок 0001 — власна реалізація.
- SRC-039: https://docs.docker.com/compose/how-tos/startup-order/ — залежності, readiness через healthcheck, завершення одноразової операції. Умови не є гарантією доступності після старту.

Для реалізації також використано технічні довідки FastAPI щодо Docker (https://fastapi.tiangolo.com/deployment/docker/) й argon2-cffi API (https://argon2-cffi.readthedocs.io/en/stable/api.html), прочитані під час початку реалізації 05.11.2026. У тексті 3.1 параметри Argon2 не приписуються новій бібліотеці чи новим джерелам: вони зберігають проєктну політику 2.3 і джерело [31]. Ці довідки не додаються окремими номерами для кількості.

Таблиця версій і результати виконання походять із `tests/evidence/2026-11-06/`, а не із зовнішніх вебсторінок. Порівняльних вимірювань FastAPI/Django, продуктивності СКБД або відповідності юридичним вимогам не виконано.
