## Правила подальшого поповнення

Для нового джерела зберігати назву, автора або організацію, версію за наявності, URL/DOI, дату звернення, місце перевіреного твердження та місце посилання в роботі. Додавати лише фактично використані матеріали. Для мінливих можливостей продуктів повторювати перевірку під час написання відповідного підрозділу; висновки за документацією відокремлювати від результатів власного тестування.
