# Контекстна модель DFD-CONTEXT-01

Редакція: 24.10.2026. Схему створено через Drawio MCP у нотації Gane–Sarson. Актуальна геометрія — context-dfd.drawio та однойменний аркуш coursework-diagrams.drawio; PNG/SVG експортовано локальним офіційним редактором Drawio. context-dfd.json зберігає семантичний склад ролей і потоків; його початкові координати більше не є джерелом геометрії. Повний проєктний обсяг і ID F1–F8 збережено.

Рисунок 1.1 у записці. Контекст подано окремо від майбутнього Level 0 за наданою методичкою. Сховище, сервер, механізм часу й автентифікація є внутрішніми складниками P0. Зовнішніх інтеграцій у базовій моделі немає. Пунктирні перспективні зв’язки не додавалися.

| ID | Джерело → одержувач | Назва | Склад даних |
|---|---|---|---|
| F1 | Заявник → Система | Дані звернення | Дані нової заявки, уточнення, публічні коментарі, запити пошуку й перегляду, підтвердження рішення або пояснення повернення в роботу. |
| F2 | Система → Заявник | Відомості власної заявки | Номер, стан, публічна історія, запити уточнення, рішення, внутрішні сповіщення заявнику та результати операцій у межах його власних заявок. |
| F3 | Спеціаліст → Система | Дані опрацювання | Запити перегляду дозволених заявок, публічні коментарі, внутрішні нотатки, дані переходів станів і опис рішення з урахуванням призначення виконавцем. |
| F4 | Система → Спеціаліст | Доступні заявки | Заявки дозволених черг, призначення виконавця, історія належної видимості, часові показники, сповіщення та результати операцій. |
| F5 | Координатор → Система | Дані розподілу | Рішення про призначення й перепризначення, уточнення пріоритету до першого призначення, публічні відповіді та параметри запитів заявок і зведень у своїх чергах. |
| F6 | Система → Координатор | Зведення й ескалації | Дані заявок своїх черг, виконавці, історія, показники строків, агреговані зведення, повідомлення про прострочення та результати операцій. |
| F7 | Адміністратор → Система | Дані налаштувань | Запити перегляду й зміни користувачів, ролей, членства в чергах, категорій і параметрів строків. |
| F8 | Система → Адміністратор | Стан налаштувань | Адміністративні дані, поточні значення параметрів, результати змін і помилки; без змісту заявок лише на підставі адміністративної ролі. |

## Узгодження й подальше використання

- Показано повний проєктний обсяг; це не схема реалізованого прототипу.
- Прикладна логіка, сховище, навчальні облікові записи й механізм часу містяться всередині процесу P0.
- Дані входу до системи та результат перевірки облікового запису агреговано в потоках відповідної ролі; окремої зовнішньої служби автентифікації немає.
- Кожний вихідний потік охоплює також результати успішних операцій, відмови та помилки для відповідного користувача.
- На етапі декомпозиції в підрозділі 2.1 зберегти зовнішні ролі, напрямки та склад F1–F8. Якщо склад змінюється, оновити контекст, текст, доступи й відповідні вимоги разом.
- Потік є сукупністю даних, а не стрілкою порядку кліків. Підтвердження закриття є частиною F1; технічні дії з ремонту не є автоматизованими діями P0.
- Зображення не доводить реалізацію авторизації, сповіщень або контролю строків.
