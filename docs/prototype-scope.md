# Реалізований обсяг прототипу

Дата: 06.11.2026. Код — `prototype/`, запуск — `README.md`, результат — `tests/results.md`. Реалізовано базовий сценарій, а не повний контракт або всі вимоги.

## Операції

Реалізовано API-LOGIN/ME/LOGOUT, API-01/02/03/04/06/07/08/09/14/15: 13 із 33. API-04 підтримує лише перше призначення; API-06 — assigned → in_progress → resolved → closed; API-07 — public. API-02 підтримує список і пагінацію; додаткові фільтри явно відхиляються. Повний OpenAPI залишається специфікацією проєкту; автоматична схема FastAPI вимкнена, щоб не підміняти нею повний контракт.

## Транзакції й безпека

- Усі успішні змінювальні API-запити фіксуються після завершення обробника й до повернення HTTP-відповіді; помилки відкочують транзакцію. SQLAlchemy використовує асинхронний psycopg.
- Прийнято стандартний PostgreSQL READ COMMITTED, row locks і expectedVersion; lock_timeout=3s, statement_timeout=10s, connect_timeout=5s. Автоматичні повтори транзакцій не реалізовані; помилка БД дає 503 без підтвердження зміни.
- Створення серіалізується блокуванням users у межах одного заявника; унікальність user_id/operation_key й digest нормалізованого JSON не дозволяють повторний запис. Це простий компроміс навчального обсягу, не твердження про незалежне масштабування всіх створень одного користувача.
- Argon2id через argon2-cffi: m=19456 KiB, t=2, p=1. Хешування пароля виконується поза event loop. Серверний сеанс, digest токенів, TTL 8h, Secure/HttpOnly/SameSite cookie, CSRF/Origin і перевірка active застосовані в коді. Повний аудит безпеки не виконано.
- Ліміти входу — пам’ять одного процесу; після restart вони скидаються. Один worker відповідає цій межі. Керування паролями та користувачами поза seed не реалізовано.
- Роль coursework_app не є власником БД; немає DELETE, UPDATE comments/history_events чи DDL. Для row locks на довідниках надані окремі UPDATE-привілеї на version/revision. Міграції й seed виконуються окремим owner-користувачем.
- У логах є UTC/метод/шаблон маршруту/статус/тривалість/correlation ID. Діагностика не доводить виконання семиденного очищення: зараз є лише Docker-ротація за обсягом.

UI відповідає основним формам і станам макетів, але не є точним графічним відтворенням усіх 12 макетів. Перевірка клавіатури, контрасту та прив’язки всіх помилок до полів залишається відкритою. Секрети локального навчального середовища не входять до доказів чи академічної записки.
